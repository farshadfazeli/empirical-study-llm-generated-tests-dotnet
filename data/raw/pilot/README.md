# Pilot: Ardalis.GuardClauses

This pilot covers one class-level target before scaling the study. The selected source file is `src/GuardClauses/GuardAgainstNullExtensions.cs`, and the separate xUnit project contains three human-written baseline tests for the `Guard.Against.Null` behavior.

The baseline currently builds against the pinned library checkout and passes with three tests. This is a validation checkpoint, not a coverage or mutation result.
