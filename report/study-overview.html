C# LLM-Generated Tests:
Coverage vs. Mutation

A deliberately limited, reproducible pilot using one .NET library, local Qwen generation, Coverlet, and Stryker.NET.

Scope boundary. This is a pilot, not a completed eight-library study. Failed generations are reported rather than hidden, and the smoke-test row is excluded from the research comparison.

Executive summary

The pipeline successfully restored, compiled, tested, covered, and mutated a valid small suite. However, the ordinary Basic Qwen generations did not compile. Consequently, this pilot cannot answer whether LLM-generated tests show a coverage-versus-mutation gap.

Method

The pilot uses the pinned Ardalis.GuardClauses checkout, one target source file, and a separate .NET 8 xUnit project. The human baseline contains three tests. Prompts, raw responses, token counts, and timestamps are stored under data/raw/llm/.

Coverlet collects Cobertura line and branch coverage. Stryker.NET 4.8.0 mutates the selected file. Validation records restore status, compiler status, test status, and output tails in data/results/validation.csv.

Reproducibility

  • Library commit and candidate information are recorded in libs.csv.
  • Stryker is pinned in .config/dotnet-tools.json.
  • API configuration is environment-only; no key is stored in code or Git.
  • Raw reports and analysis-ready CSV files are retained.

Discussion and limitations

The main pilot finding is procedural: compile validity must be established before coverage and mutation scores can be compared. The local Qwen model produced several outputs with Markdown, missing imports, invalid identifiers, incomplete braces, or invalid assertions. Those failures are part of the result.

  • One model and one small library limit generalizability.
  • Public code may have been present in the model's training data.
  • Mutation results depend on Stryker.NET operators and filters.
  • No manual survivor classification was performed.
  • Coverage values are aggregate assembly values and should not be generalized.

Conclusion

The limited pilot provides no evidence for or against the proposed coverage-versus-mutation relationship. It does provide a reproducible pipeline, visible failure records, and end-to-end measurement smoke-test reports. A larger study should begin only after a genuinely model-generated suite can be produced and validated.
